# India Knowledge Graph (IKG)

## User Personas & Experience Design

Version: 1.0

Status: Active

Owner: Product Management

Priority: Critical

---

# Purpose

India Knowledge Graph exists to help people understand Indian affairs through verified, interconnected knowledge.

This document defines who those people are.

Every feature, API, workflow, interface and AI decision must solve a problem for at least one user persona described here.

If a proposed feature cannot be mapped to a user persona, it should not be implemented.

---

# Product Philosophy

IKG is designed for people who want to understand.

Not scroll.

Not consume.

Not be entertained.

Users visit IKG with intent.

Every interface should respect that intent.

---

# User Categories

The platform serves five primary personas.

1. UPSC Aspirants

2. Researchers

3. Journalists

4. Professionals

5. General Readers

Future versions may introduce enterprise users.

---

====================================================

PERSONA 1

====================================================

# UPSC Aspirant

## Description

A student preparing for Civil Services examinations.

Usually studies between 2 and 6 hours daily.

Consumes large volumes of Current Affairs.

Needs historical context.

Needs revision.

Needs trust.

Not interested in sensational news.

---

## Goals

Understand today's developments.

Track long-running issues.

Remember important events.

Prepare revision notes.

Study government policies.

Study Parliament.

Connect economics with current affairs.

Reduce reading time.

---

## Pain Points

Reads multiple websites.

Cannot remember chronology.

Duplicate articles.

Needs manual note making.

No easy revision.

No relationship mapping.

No verification.

---

## Desired Outcome

Open platform.

Read one Event.

Understand everything.

Move to next topic.

---

User Emotions

====================================================

The interface should create the following emotions.

Confidence

Curiosity

Clarity

Calmness

Discovery

Never

Stress

Confusion

Overwhelm

Urgency

Addiction

---

====================================================

Cognitive Load Rules

====================================================

One screen.

One purpose.

Maximum three primary actions.

Avoid dashboards with dozens of widgets.

Every page should have visual hierarchy.

Whitespace is encouraged.

Never make users think.

---

====================================================

Accessibility

====================================================

Desktop First

Tablet Ready

Mobile Friendly

Keyboard Accessible

Dark Mode

Light Mode

Readable Typography

Minimal Motion

---

====================================================

Success Metrics

====================================================

The product succeeds if users

Need fewer tabs open.

Read fewer duplicate articles.

Understand Events faster.

Discover relationships naturally.

Trust the platform.

Return daily.

Recommend it to others.

---

====================================================

Failure Metrics

====================================================

Users become confused.

Graph feels overwhelming.

Cannot understand verification.

Cannot distinguish Events.

Search produces irrelevant results.

Too much AI.

Too much text.

Too many clicks.

---

====================================================

North Star Metric

====================================================

The success of India Knowledge Graph is measured by one question.

"Did the user leave understanding the topic better than when they arrived?"

If the answer is yes,

the platform succeeded.

If not,

every engineering decision should be reconsidered.
